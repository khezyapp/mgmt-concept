## Start by situation

Use this table as the cookbook index. Each row points to the shortest useful path.

| Situation | Start with | Output |
|---|---|---|
| A new strategy, policy, or instruction just landed | [04 — New Document SOP](/strategy-to-action/04-new-document-sop) | Triage card and response |
| I need to understand what a document actually asks | [02 — Decoder](/strategy-to-action/02-decoder) | Plain-English obligations |
| I have an objective but no delivery plan | [03 — Traceability](/strategy-to-action/03-traceability) + [05 — Proposal Playbook](/strategy-to-action/05-proposal-playbook) | Initiative and tasks |
| I must justify a project or budget | [05 — Proposal Playbook](/strategy-to-action/05-proposal-playbook) | One-page proposal |
| I need a measure for a commitment | [06 — Templates](/strategy-to-action/06-templates) §3–4 | Objective and KPI cards |
| I must prove the work happened | [06 — Templates](/strategy-to-action/06-templates) §10 | Audit test case |
| A term is being used loosely | [08 — Glossary](/strategy-to-action/08-glossary) | Definition and distinction |
| I need the whole model on one screen | [01 — Cheat Sheet](/strategy-to-action/01-cheatsheet) | Decode, trace, act |

## How to review this site

- **Before a meeting:** read the [cheat sheet](/strategy-to-action/01-cheatsheet) and
  the relevant definition in the [glossary](/strategy-to-action/08-glossary).
- **When a document arrives:** run the [60-minute SOP](/strategy-to-action/04-new-document-sop).
- **When you need to produce something:** copy the matching form from
  [templates](/strategy-to-action/06-templates).
- **When you need a full example:** follow the
  [worked example](/strategy-to-action/07-worked-example).
